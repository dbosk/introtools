Sometimes (most times, actually) it's nice to have someone to work with,
to air thoughts and discuss problems and possible solutions.

There are various solutions available that solve different parts of the
problem. You've encountered [Zoom](https://kth-se.zoom.us) for video
conferencing. While Zoom supports sharing the screen, it needs a
complement sometimes.

One such complement is [tmate](https://tmate.io). This is available as
the command `tmate` on KTH systems (e.g. `student-shell`). When you
start tmate, it opens a terminal session that *others can join*, giving
you the possibility to work in a group in the same terminal. For
instance, when you ask for help during the remote lab sessions, tmate
might be useful.

## Some useful tools

Video chat:

-   [Zoom](https://kth-se.zoom.us)
-   [Jitsi](https://meet.jit.si/)
-   [Teams](https://teams.microsoft.com/start)
-   [Discord](https://discord.com)

Asynchronous chat:

-   [Zulip](https://zulipchat.com)
-   [Slack](https://slack.com)
-   [Teams](https://teams.microsoft.com/start)
-   [Discord](https://discord.com)

Terminal sharing and pair programming:

-   [tmate](https://tmate.io)
-   plugins for
    [various](https://www.microverse.org/blog/how-remote-pair-programming-works-and-why-it-can-change-your-life)
    [editors](https://www.sitepoint.com/collaborative-coding-tools-for-remote-pair-programming/)

Explore some of these tools to get a feel for what they can do and which
you like the most.

# Pair programming

You should read two articles:

1.  [Strengthening the Case for Pair
    Programming](https://eu.feedbackfruits.com/courses/activity-course/1a3d3978-afbe-43d2-9d4a-216c3f21efe9)
    (just signup if you don't have a FeedbackFruits account already)
2.  [The Costs and Benefits of Pair
    Programming](https://eu.feedbackfruits.com/courses/activity-course/73587dce-a191-44ad-8b60-e1ae2744963b)

The first is from an academic magazine (lighter to digest) and the
second is a scientific article ("has a bit more fibre" and requires the
first for background details).

You can also see [this
guide](https://gist.github.com/rouzbeh84/4bafc9fe4fe02edf506d11997c4674b0)
for more practical suggestions on pair programming.
