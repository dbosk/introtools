There are two ways to use LaTeX: 1) install it locally, 2) use a web
service.

The first is to install it locally on your computer. For Windows we
recommend
[MikTeX](https://miktex.org/howto/install-miktex){.inline_disabled
target="_blank"}. For macOS and Linux (also WSL) we recommend TeX Live.
On Linux and WSL, it\'s just to run `sudo apt install texlive-full`. On
macOS you can have a look at
[MacTeX](https://www.tug.org/mactex/){.inline_disabled target="_blank"}.

For the online service option, [KTH provides OverLeaf Professional to
all students](https://www.overleaf.com/edu/kth){.inline_disabled
target="_blank"}.

Once you\'ve installed LaTeX or registered for OverLeaf, hit the Next
button below.
